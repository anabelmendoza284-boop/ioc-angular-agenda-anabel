# Agenda Personal - Proyecto Angular (EAC1)

Este proyecto forma parte de la EAC1 del módulo de Aplicaciones Web del IOC.  
La aplicación muestra una estructura básica con cabecera, contenido principal y pie de página.

## Tecnologías utilizadas
- Angular 17
- TypeScript
- SCSS
- Visual Studio Code

## Estructura inicial
- `app.component.html`: contiene la estructura visual (header, main y footer).
- `app.component.scss`: contiene los estilos básicos.
- `app.component.ts`: propiedad pública `title = 'Agenda personal';`.

## Hot Reload
El proyecto utiliza hot reload.  
Al modificar cualquier archivo HTML o SCSS, la página se actualiza automáticamente sin reiniciar el servidor.
